Sump Pump Monitor 0.4.16

Based on 0.4.13

Changes:
- Completed pump cycles now fire the Home Assistant event
  `sump_pump_monitor_cycle_completed`.
- Event data includes pump_id, pump_name, start, end, duration,
  average_power, and peak_power.
- Cycle start/end values in the event are ISO-8601 local-time timestamps.
- Persistent retained cycle history remains in the integration Store and is
  still subject to the configured history-days and maximum-cycle retention.
- Cycle History is now a compact summary sensor rather than a large list or
  numeric duration measurement. Its state is the number of retained cycles,
  with latest-cycle and retention information in attributes.
- No polling was added; the existing state-change subscription remains the
  source of pump state transitions.
- Version bumped to 0.4.16.
